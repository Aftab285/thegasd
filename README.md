# Gujarati Association of San Diego (GASD) Website

Official landing page for the **Gujarati Association of San Diego (GASD)**.

## Overview
A responsive website built with HTML5 and CSS3:
- **Top Toran Framing**: Hand-crafted traditional toran border with custom angled cuts framing the circular emblem.
- **Header & Navigation**: Clean white navigation bar with active states and centered GASD emblem.
- **Hero Section**: Bright panoramic San Diego and Gujarati heritage landscape with dark navy typography and four primary call-to-action buttons.
- **Who We Are**: Introduction to GASD with Balboa Park California Tower backdrop and four core pillar cards (*Cultural*, *Educational*, *Charitable*, *Community*).
- **Upcoming Events**: Event showcase with floating date badges, event categories, and quick links.
- **GASD Membership**: Benefits overview, traditional cultural photography, and membership call-to-action.
- **Focus Pillars**: Dedicated cards for Cultural Events, Educational Support, and Charitable Initiatives.
- **Community Gallery**: 5-photo strip celebrating cultural moments, temple architecture, and San Diego landmarks.
- **Stay Connected**: Clean newsletter subscription form.
- **Footer**: Brand information, quick navigation links, contact details, and decorative bottom toran border.

## Technologies Used
- HTML5
- CSS3 (Custom Responsive Layouts, Flexbox, CSS Grid)
- Google Fonts (*Playfair Display*, *Inter*)
- Font Awesome 6.5.1
